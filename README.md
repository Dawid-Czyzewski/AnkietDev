# AnkietDev

A modern web platform for creating, managing, and analyzing online surveys.

## Scope

- home page
- registration and login
- user dashboard
- survey creation and editing
- survey statistics and results
- contact page
- bilingual support (PL / EN)

## Technologies

- PHP
- React 19
- Tailwind CSS
- React Router
- i18next / react-i18next
- MySQL
